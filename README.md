# Student Engagement System 

A web application built with Flask and TensorFlow (CNN model) to analyze and monitor student engagement states from uploaded images.

## Tech Stack
* **Backend:** Python, Flask, Flask-SQLAlchemy, Flask-Login
* **Deep Learning:** TensorFlow / Keras (CNN model for image classification)
* **Image Processing:** Pillow (PIL)
* **Frontend:** HTML, CSS

## Project Workflow
1. User Sign Up / Login securely.
2. Navigate to the State Prediction page.
3. Upload a student image file.
4. The CNN model analyzes the image and displays the engagement state (e.g., Stressed, Attentive) with confidence levels.
